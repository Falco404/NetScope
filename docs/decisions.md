# Decisions

Newest at the bottom. Record every decision: date, what, why, alternatives.

| Date | Decision | Why | Alternatives considered |
|---|---|---|---|
| 2026-11-23 | GUI is a **web app** (FastAPI JSON API + static vanilla JS), not PyQt6 | Runs anywhere (Windows browser, Fedora, phone on the LAN) and the interesting logic lives in tested API endpoints instead of untested widgets. User approved. | PyQt6 desktop window; Flask+Jinja; Textual TUI |
| 2026-11-23 | Target restriction lives **in code**, not config (`TargetGuard`, RFC1918 only) | AGENTS.md rule: refusing non-private targets must be enforced in the scanner itself, so a bad target can never reach nmap. Config-file limits could be edited away. | allowlist in env var; blocking at the UI only |
| 2026-11-23 | `IPv4Network(target, strict=False)`; check **both ends** of the CIDR against the allowed ranges | Single IPs and CIDRs both parse; a range that spills outside RFC1918 (e.g. `172.31.0.0/11`) is refused even though its network address looks valid; IPv6 raises. | network-address check only; regex validation |
| 2026-11-23 | Scanner behind an `NmapRunner` interface; tests replay recorded XML fixtures | AGENTS.md: scanner logic testable without a network. Fake runner = zero packets in CI. | monkeypatching subprocess; live scans in tests |
| 2026-11-23 | Two-pass scan: `-sn` discovery, then `-sV` (later `-sV -O`) on live hosts only | A `/24` stays fast — version/OS probing only runs on hosts that answered. | single `-A` pass over the whole subnet (slow); probing every address |
| 2026-11-23 | Device identity = **MAC when known, else IP**, never renamed once assigned | MAC survives DHCP leases, so one machine never forks into two rows across scans. | IP as primary key; hostname as key |
| 2026-11-23 | Store upsert uses **COALESCE** for hostname/OS/vendor | A scan that learns nothing must not blank fields an earlier scan filled in. Ports are a fresh snapshot per scan. | full overwrite per scan; append-only rows |
| 2026-11-23 | Schema version via `PRAGMA user_version`; no migration framework | One small local DB; bumping `_SCHEMA` + version is enough at this stage. | Alembic; JSON file store |
| 2026-11-23 | **Small offline OUI registry** (7 prefixes), not the ~2 MB IEEE dump | User said verbatim: "okay dont include the full dump, current system is fine". nmap's own vendor DB is the primary source; registry is a fallback with no runtime network calls. | full IEEE CSV; online OUI lookup |
| 2026-11-23 | One scan at a time; second POST while running returns **409**; illegal target returns **400** from the server | nmap subprocesses would overlap and double the LAN traffic; the guard must be server-side so any client is protected. | queued scans; concurrent scans; client-side-only validation |
| 2026-11-23 | Server binds `127.0.0.1` by default; `0.0.0.0` only via explicit `NETSCOPE_HOST` | The UI has no auth, so a LAN bind would let any LAN client trigger scans. Kept as an opt-in; user has not answered this yet. | default `0.0.0.0` for phone access; adding auth now |
| 2026-11-23 | Runner errors are turned into **actionable messages** and shown in the UI | A bare `[Errno 2] nmap` made the UI look broken; it now says how to install nmap or that a pass timed out. | silent error state; traceback to console |
| 2026-11-23 | nmap timeout is **per pass**, configurable via `NETSCOPE_NMAP_TIMEOUT` (default 300 s) | Guarantees a scan can never hang forever; worst case two passes ≈ 10 min. UI shows elapsed + limit instead of a fake progress percentage. | global scan timeout; no timeout; progress bar percentage |
| 2026-11-23 | Tests must not assume **POSIX binaries** — exit-code tests use `sys.executable` + `SystemExit(n)` | CI matrix is Linux-only, Falco runs tests on Windows; a test using `false` failed there. Rule recorded in docs/gotchas.md. | skip the test on Windows; shell-dependent fixtures |
| 2026-11-23 | Parser reads nmap's **`portid`** attribute and skips a `<port>` without one, never fabricating `port 0` | Real scans showed `0/tcp` for every device: the parser read a non-existent `port` attribute. Fixtures had invented the same attribute, so 71 tests passed while real scans were wrong — fixtures must mirror real nmap XML. | tolerate both attribute names (would keep hiding bugs) |
| 2026-11-23 | Added `-O` OS fingerprinting to the service pass (#19) | M7 wants Atom/Apollo recognisable; OS was always empty because `-O` never ran. Needs raw-socket privileges, so the column can stay empty without admin PowerShell. | `-A` (heavier, slower); leave OS detection out |
| 2026-11-23 | UI prefills the target from `GET /api/local-subnet`, **assuming a `/24` mask** (field stays editable, public IPs return `null`) | The hardcoded `192.168.1.0/24` was wrong for the home LAN. Detection uses a UDP socket `connect()` — sends no packet — and re-checks the result against TargetGuard. Reading the real interface mask portably on Windows needs extra deps, so `/24` is assumed and labelled "assumed". | keep manual field only; `netifaces`/`psutil` dependency; guess from gateway |
| 2026-11-23 | Admin-vs-normal PowerShell requirement is **recorded as unverified** in README | Falco only tested admin PowerShell (~290 s for the `/24`) and asked for the uncertainty to be remembered rather than resolved. | assert admin is required; assert normal works |
| 2026-11-23 | Handoff protocol: commit/push everything, PR + `docs/STATUS.md` + `docs/decisions.md` updated, then a paste-ready prompt | AGENTS.md Handoff section; the new session must be able to start cold. | continue the long session; rely on chat history |
| 2026-11-23 | M8 naming: **manual `device_names` table editable in the UI** (schema v2, `PRAGMA user_version = 2`), manual name beats hostname/vendor in `display_name`; v1 DBs upgraded in place by adding the table | Router answers no PTR so devices show bare IPs; NetBIOS broadcast cannot name Linux hosts (Atom/Apollo don't speak NetBIOS) and ARP pairs MAC↔IP but has no names, so only a user-set label reliably names your own devices. Names live in their own table, never touched by scans. | `nmap --script broadcast-nbname`; ARP alias import; editing the scan-learned hostname field |
| 2026-11-23 | Admin PowerShell is **NOT required** for scans | Falco ran NetScope in a regular PowerShell window: two `/24` scans completed unprivileged (271.77 s and 236.08 s); only `-O` OS guesses stay empty (raw-socket privileges). | asserting admin is required |
| 2026-11-23 | AGENTS.md **stays silent** on the RFC1918 restriction | Falco decided explicitly: enforcement belongs in code (TargetGuard at every scan entry point), not in the prose rule. | restoring the restriction in AGENTS.md |
| 2026-11-23 | `0.0.0.0` bind + auth **deferred** to a future issue | Falco has not decided yet; localhost default stays so the unauthenticated UI is not LAN-reachable. | decide now; ship auth before exposing |
